# How to Speed Up a Slow Computer (Without Buying New Parts)

Your computer was fast when you bought it. Now it takes forever to boot, programs lag, and opening a browser tab feels like launching a rocket. Before you spend money on a new machine, try these fixes — most slow computers can be revived with software changes alone.

## First: Find Out What's Actually Slow

Don't guess. Check what's using your resources.

### Windows: Task Manager
1. Press **Ctrl + Shift + Esc** to open Task Manager.
2. Click **More details** if you see a simplified view.
3. Click the **CPU** column to sort by highest usage.
4. Click the **Memory** column to see what's eating RAM.
5. Click the **Disk** column to see if your hard drive is maxed out.

**What to look for:**
- **CPU above 80%** with nothing obvious running = something is wrong.
- **Memory above 80%** = you need more RAM or need to close programs.
- **Disk at 100%** = your hard drive is the bottleneck (common with HDDs).

### Mac: Activity Monitor
1. Press **Cmd + Space**, type **Activity Monitor**, press Enter.
2. Click the **CPU** tab to see what's using processing power.
3. Click the **Memory** tab to check RAM usage.
4. Look for processes using an unusually high percentage.

## The Top Free Fixes (In Order of Impact)

### 1. Disable Startup Programs (Huge Impact)

Most computers ship with dozens of programs that launch at startup. Each one eats memory and slows boot time.

**Windows 10/11:**
1. **Ctrl + Shift + Esc** → Task Manager → **Startup apps** tab.
2. **Right-click** programs you don't need at startup → **Disable**.
3. **Safe to disable:** Spotify, Discord, Zoom, Teams, Adobe updaters, printer software, manufacturer bloatware.
4. **Keep enabled:** Antivirus, audio drivers, cloud sync (OneDrive, Dropbox) if you use it.

> **Typical result:** Boot time drops from 3-5 minutes to 30-60 seconds.

**Mac:**
1. **Apple menu** → **System Settings** → **General** → **Login Items**.
2. Remove apps you don't need at startup.

### 2. Clear Temporary Files (Frees Significant Space)

Windows keeps temporary files that accumulate over months. They eat space and can slow things down.

**Windows 10/11:**
1. **Settings** → **System** → **Storage**.
2. Turn on **Storage Sense** (automates cleanup).
3. Click **Temporary files** → select everything → **Remove files**.

**Or use Disk Cleanup:**
1. Press **Win + S**, type **Disk Cleanup**.
2. Select your C: drive.
3. Check **Temporary files, Recycle Bin, Thumbnails, Delivery Optimization Files**.
4. Click **Clean up system files** for even more (old Windows updates).

**Mac:**
1. **Apple menu** → **About This Mac** → **Storage** → **Manage**.
2. Enable **Store in iCloud** and **Optimize Storage**.
3. Click **Review Files** under Documents to find large files.

### 3. Uninstall Programs You Don't Use

Every installed program takes space and some run background processes.

**Windows:**
1. **Settings** → **Apps** → **Installed apps**.
2. Sort by **Size** to find the biggest space hogs.
3. Uninstall anything you haven't used in 3+ months.

**Common space hogs to remove:**
- Old games
- Manufacturer bloatware (HP Smart, Dell SupportAssist, Lenovo Vantage — unless you use them)
- Multiple browsers (pick one)
- Old Java versions
- Trial software you never activated

### 4. Check for Malware

Malware is a common cause of sudden slowdowns.

**Windows:**
1. **Windows Security** (built-in) → **Virus & threat protection** → **Full scan**.
2. Also run **Microsoft Defender Offline scan** for deeper checking.
3. For a second opinion: download **Malwarebytes** free version, run a scan, uninstall after.

**Mac:**
1. **System Settings** → **Privacy & Security** → **Security**.
2. Ensure **Allow apps downloaded from: App Store and identified developers** is set.
3. Run a free scan with **Malwarebytes for Mac**.

### 5. Reduce Visual Effects (Makes Old Computers Feel Snappy)

Windows has visual animations that use CPU and RAM. Turning them off makes the system feel faster.

**Windows 10/11:**
1. Press **Win + S**, type **Adjust the appearance of Windows**.
2. Select **Adjust for best performance**.
3. Or manually check only: **Smooth edges of screen fonts** and **Show thumbnails instead of icons** (keeps it usable without looking ugly).

**Mac:**
1. **System Settings** → **Accessibility** → **Display**.
2. Enable **Reduce motion** and **Reduce transparency**.

### 6. Defragment Your Hard Drive (HDD Only)

**Skip this if you have an SSD** — SSDs don't need defragmentation and it reduces their lifespan.

**Windows:**
1. Press **Win + S**, type **Defragment**.
2. Select your hard drive (not the SSD if you have both).
3. Click **Optimize**.

> **Note:** Windows 10/11 usually runs this automatically on a schedule. Check that it's enabled.

### 7. Update Everything

Outdated drivers and software can cause performance issues.

- **Windows Update:** Settings → Windows Update → Check for updates.
- **Graphics driver:** Download latest from NVIDIA/AMD/Intel website (not from Windows Update — it's often outdated).
- **Browser:** Update Chrome/Firefox/Edge to latest version.
- **Mac:** System Settings → General → Software Update.

## If Software Fixes Aren't Enough: Hardware Upgrades

### Upgrade to an SSD (Best bang for buck)
If your computer still uses a hard drive, this is the **single biggest upgrade** you can make.
- **Boot time:** 2-3 minutes → 15-20 seconds.
- **Program launch:** 10-30 seconds → 1-3 seconds.
- **Cost:** $50-100 for a 500GB SSD.
- **Difficulty:** Moderate (requires cloning your existing drive or fresh Windows install).

### Add More RAM
Only helps if you're running out of RAM (check Task Manager > Memory).
- **8GB minimum** for modern Windows.
- **16GB** recommended for multitasking.
- **Cost:** $30-60 for 8-16GB.
- **Check compatibility:** Use [Crucial System Scanner](https://www.crucial.com/store/systemscanner) to find compatible RAM.

### Clean the Dust
Overheating causes throttling — the CPU slows itself to avoid damage.
1. **Power off and unplug** the computer.
2. **Open the case** (desktop) or **bottom panel** (laptop).
3. **Use compressed air** to blow dust out of fans and heat sinks.
4. **Pay attention to** CPU fan, GPU fans, and case fans.

> **Laptop warning:** Some laptops are difficult to open. Watch a YouTube tutorial for your specific model first.

## The Restart Rule

Restarting your computer at least once a week:
- Clears RAM (frees memory from leaked processes).
- Finishes pending updates.
- Resets stuck drivers.
- Kills background processes that accumulated.

**If your computer is slow right now and you haven't restarted in days, restart it.** This alone might fix the problem.

---

## When to Accept Defeat

Sometimes the hardware is genuinely too old:
- **CPU more than 8 years old:** Software can only do so much.
- **4GB RAM on Windows 10/11:** Not enough for modern web browsing.
- **Hard drive failing:** If Task Manager shows 100% disk usage constantly and the drive is old, it may be dying. Back up immediately and replace it.

If you've tried everything above and the computer is still painfully slow, it may be time for a new one. But try the SSD upgrade first — it's amazing what it does for computers that are 5-7 years old.

## The Bottom Line

**Disable startup programs** (free, huge impact), **clear temporary files** (free, frees space), **upgrade to an SSD** (best $50-100 upgrade possible). These three changes alone can make a 5-year-old computer feel like new.
