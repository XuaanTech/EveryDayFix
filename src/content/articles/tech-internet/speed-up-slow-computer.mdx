# How to Speed Up a Slow Computer

A slow computer can turn a 5-minute task into a 30-minute ordeal. Whether it takes forever to boot, lags when switching between apps, or freezes randomly — the frustration is real.

Before you spend money on a new computer, try these fixes. Most slow computers can be significantly improved with a few simple changes.

## Check What's Slowing It Down

Before fixing anything, identify the bottleneck.

**On Windows:**
1. Press **Ctrl + Shift + Esc** to open Task Manager.
2. Click **"More details"** if needed.
3. Check the **Processes** tab for high CPU, Memory, or Disk usage.
4. If something is consistently using 80%+ of resources, that's your problem.

**On Mac:**
1. Open **Activity Monitor** (search in Spotlight).
2. Check the **CPU**, **Memory**, and **Disk** tabs.
3. Sort by % CPU to find the heaviest processes.

## Fix 1: Restart Your Computer

It sounds too simple, but restarting clears temporary files, resets memory, and stops runaway processes.

- **Restart at least once a week** — don't just close the lid.
- If your computer has been running for days without a restart, do it now.

## Fix 2: Disable Startup Programs

Too many programs launching at startup is one of the most common causes of slowness.

**On Windows 10/11:**
1. Press **Ctrl + Shift + Esc** → **Startup** tab.
2. Right-click unnecessary items → **Disable**.
3. Keep only essential items (antivirus, cloud sync).

**On Mac:**
1. Go to **System Settings** → **General** → **Login Items**.
2. Remove unnecessary apps from "Open at Login."

> **Safe to disable:** Spotify, Discord, Steam, Skype, OneDrive (if not needed), Adobe updaters.

## Fix 3: Clear Temporary Files

Windows and apps accumulate temporary files that waste space and can slow things down.

**On Windows:**
1. Press **Windows + R**, type `temp`, press Enter → delete everything.
2. Press **Windows + R**, type `%temp%`, press Enter → delete everything.
3. Run **Disk Cleanup:** Search "Disk Cleanup" in Start menu → select drive → check all boxes → OK.

**On Mac:**
1. Open **Finder** → **Go** → **Go to Folder**.
2. Type `~/Library/Caches` → delete the contents of cache folders.
3. Empty the Trash afterward.

## Fix 4: Uninstall Unused Programs

Old programs you no longer use still take up space and may run background processes.

**On Windows:**
1. Go to **Settings** → **Apps** → **Installed apps**.
2. Sort by **size** or **install date**.
3. Uninstall anything you don't use.

**On Mac:**
1. Open **Finder** → **Applications**.
2. Drag unused apps to the Trash.
3. Empty the Trash.

## Fix 5: Disable Visual Effects

Windows has fancy visual effects that consume resources on older hardware.

**On Windows:**
1. Search for **"Adjust the appearance of Windows"** in the Start menu.
2. Select **"Adjust for best performance"** or manually uncheck effects you don't need.
3. Click **Apply**.

## Fix 6: Run a Malware Scan

Malware running in the background is a common cause of sudden slowness.

**On Windows:**
1. Open **Windows Security** (built-in).
2. Go to **Virus & threat protection** → **Quick scan**.
3. For a deeper check, run a **Full scan** or use **Malwarebytes** (free version).

**On Mac:**
1. While macOS is less susceptible, still run a scan with **Malwarebytes for Mac** (free).

## Fix 7: Update Everything

Outdated software can cause performance issues.

- **Windows Update:** Settings → Windows Update → Check for updates.
- **macOS Update:** System Settings → General → Software Update.
- **Driver updates:** Especially graphics and network drivers.
- **App updates:** Update your most-used applications.

## Fix 8: Add More RAM (If Applicable)

If Task Manager shows memory usage consistently above 80%, you may need more RAM.

- **8 GB RAM** is the minimum for comfortable modern use.
- **16 GB** is ideal for most users.
- Check if your computer's RAM is upgradeable (many laptops aren't anymore).

## Fix 9: Upgrade to an SSD

This is the **single biggest upgrade** you can make.

- If your computer still uses a hard drive (HDD), switching to a solid-state drive (SSD) can make it feel like a new machine.
- Boot times drop from minutes to seconds.
- Apps open almost instantly.
- SSDs are affordable — a 500 GB SSD costs around $25-40.

## Fix 10: Reset Your Computer (Last Resort)

If nothing else works, a fresh start can resolve deep software issues.

**On Windows:**
1. Settings → System → Recovery → **Reset this PC**.
2. Choose **"Keep my files"** to preserve your personal data.

**On Mac:**
1. Boot into Recovery Mode (hold Cmd + R during startup).
2. Reinstall macOS (your data stays intact if you choose that option).

## Prevention: Keep It Fast

- Restart weekly
- Don't install software you don't need
- Keep Windows/macOS updated
- Run a malware scan monthly
- Clear temp files monthly
- Don't let your hard drive get more than 80% full

## The Bottom Line

Start with the free, quick fixes: **restart, disable startup programs, clear temp files, and run a malware scan**. These four steps solve most performance problems.

If your computer is still slow after that, **upgrading to an SSD** is the most cost-effective improvement you can make — it's cheaper than a new computer and makes a dramatic difference.
